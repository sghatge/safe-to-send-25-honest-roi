Safe to Send · Ep 25 — "AI saved us 900 hours." Measured how?

Every AI post claims hours saved. Almost none says how.

Usually it's one estimate × campaigns × 52, presented as fact. When finance asks how it was measured, the number collapses, and so does trust in the next claim.

So this repo is a measurement tool that refuses to cheat:
→ fewer than 5 timed trials per method? It won't report
→ medians, not averages
→ a 90% range on the saving, not one headline number
→ defects found shown next to minutes saved (faster but worse isn't a saving)
→ an annual figure only if you ask, and it prints the word PROJECTION next to it
→ a closing line on what it didn't measure: setup, false alarms, upkeep, trust
